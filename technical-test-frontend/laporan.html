3. Ringkasan Fitur & Arsitektur Sistem
  • Autentikasi & Otorisasi: SPA Token Auth (Laravel Sanctum) & Spatie Role/Permission.
  • Data Masif (Seeder): 1.000 User Pemohon, 1.000 User Penilai, dan 10.000 Data Project Permohonan.
  • Workflow & Audit Logs: Riwayat kronologis (history logs) penilaian dan revisi.
  • Validasi Dokumen: Format file terverifikasi (PDF/DOCX/JPG/PNG) & max ukuran 5MB.
